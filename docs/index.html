libann

A neural network library in 5,646 lines of ANSI C, compiled to WebAssembly. Every network on this page is trained and run by that C code in your browser. Nothing is sent anywhere.

Pick a shape and watch a network carve up the plane. Tap the plot to add points. The library keeps training on the new data, one mini-batch at a time, with ann_train_step.

Draw with a finger or mouse. A 64-64-10 network classifies the 8×8 version of your drawing on every stroke. If it gets one wrong, tell it the right digit and it learns from your example.

The build uses plain clang --target=wasm32 with no Emscripten. A C shim of 989 lines supplies malloc, printf and an in-memory file system, so ann_load_network_binary reads its model with no changes. The page only feeds data in and draws what comes out.

One workaround is applied: the loader leaves weights_set at 0, so ann_train_begin would re-randomize a loaded model. The glue sets it after loading.

const net = ann_make_network(OPT_ADAM,
                             LOSS_CATEGORICAL_CROSS_ENTROPY);
ann_add_layer(net,  2, LAYER_INPUT,  ACTIVATION_NULL);
ann_add_layer(net, 12, LAYER_HIDDEN, ACTIVATION_TANH);
ann_add_layer(net, 12, LAYER_HIDDEN, ACTIVATION_TANH);
ann_add_layer(net,  2, LAYER_OUTPUT, ACTIVATION_SOFTMAX);
ann_set_learning_rate(net, 0.03);
ann_set_batch_size(net, 16);

ann_train_begin(net);
loss = ann_train_step(net, batch_x, batch_y, 16);  // repeat
ann_predict(net, point, probabilities);

net = ann_load_network_binary("digits.nnb");
clang --target=wasm32 -O3 -ffreestanding -nostdlib \
  -isystem shim -Ilibann -mbulk-memory -msimd128 \
  -c tensor.c ann.c json.c libc.c
wasm-ld --no-entry --export-all --allow-undefined *.o

libann is written by Mark Seminatore and released under the MIT license: github.com/mseminatore/ann. The digit model was trained with the library itself, on scikit-learn's 8×8 digits with added shifts, rotations and stroke-width changes. It scores about 98% on 360 held-out digits.
